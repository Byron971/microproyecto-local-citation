# Primera validación manual por parte del equipo del piloto de función de cita

Este directorio conserva la primera validación manual por parte del equipo sobre los 20 casos del piloto usado para preparar el corte del 20 de septiembre.

Archivo:
- annotator_a.csv

Estado:
- 20 de 20 casos revisados.
- Una sola etiqueta por caso, usando las nueve categorías definidas en el proyecto.
- Esta primera validación fue asistida con explicaciones de cada caso y, por tanto, no debe describirse como una anotación ciega o independiente.
- No constituye por sí sola un Test Gold definitivo.
- Para calcular el acuerdo interanotador se requiere una segunda validación manual independiente del mismo conjunto.
- El Test Gold final solo debe generarse después de reconciliar desacuerdos.

Las etiquetas de este archivo fueron confirmadas durante esta primera validación manual por parte del equipo y no deben confundirse con las sugerencias automáticas almacenadas en tests/fixtures/citation_function_prelabels.jsonl.
