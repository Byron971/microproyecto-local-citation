# Primera revisión humana del piloto de función de cita

Este directorio conserva la primera revisión humana de los 20 casos del piloto usado para preparar el corte del 20 de septiembre.

Archivo:
- annotator_a.csv

Estado:
- 20 de 20 casos revisados.
- Una sola etiqueta por caso, usando las nueve categorías definidas en el proyecto.
- Esta revisión fue asistida con explicaciones de cada caso y, por tanto, no debe describirse como una anotación ciega o independiente.
- No constituye por sí sola un Test Gold definitivo.
- Para calcular acuerdo interanotador se requiere una segunda revisión humana independiente del mismo conjunto.
- El Test Gold final solo debe generarse después de reconciliar desacuerdos.

Las etiquetas de este archivo fueron confirmadas durante la revisión humana y no deben confundirse con las sugerencias automáticas almacenadas en tests/fixtures/citation_function_prelabels.jsonl.
